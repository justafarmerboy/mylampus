# ✦ Mylampus — หิ่งห้อยฟู้ดทรัค

แผนที่ฟู้ดทรัคที่แต่ละร้านเป็น **หิ่งห้อย** บินวนไปมารอบพิกัดจริงของร้าน

- 🟢 **สว่างขึ้น** เมื่อเจ้าของกด “เปิดร้าน” (แอปส่ง GPS ของร้านขึ้นแผนที่)
- 🌗 **ค่อย ๆ หรี่ลง** ในช่วง 15 นาทีสุดท้ายก่อนหมดเวลา
- ⚫ **กะพริบแล้วดับ** เมื่อครบเวลาที่ตั้งไว้ หรือเมื่อเจ้าของกด “ปิดร้าน”
- 🚚 ถ้ารถเคลื่อนที่ หิ่งห้อยจะค่อย ๆ บินตามไปยังตำแหน่งใหม่แบบเรียลไทม์
- 📍 ลูกค้าเห็นว่าตำแหน่งอัปเดตล่าสุดเมื่อไร ถ้าเกิน 5 นาที (เช่น เจ้าของปิดจอ) หิ่งห้อยจะบินช้าลงและแสดงอายุตำแหน่งข้างชื่อร้าน

## เริ่มใช้งาน

ต้องใช้ Node.js 18 ขึ้นไป ไม่มี dependency ให้ติดตั้ง

```bash
npm start          # http://localhost:3000
npm test
```

| หน้า | สำหรับ |
| --- | --- |
| `/` | ลูกค้า: แผนที่หิ่งห้อย แตะหิ่งห้อยเพื่อดูรูปร้าน เมนูอาหาร/เครื่องดื่มพร้อมรูปและราคา เวลาปิด และนำทาง |
| `/owner` | เจ้าของร้าน: ลงทะเบียน ใส่รูปหน้าร้าน จัดการเมนู (ชื่อ ราคา รูป อาหาร/เครื่องดื่ม ของหมด) เลือกสีแสง เปิดร้าน (เลือกระยะเวลา 15 นาที–1 ชม.) ต่อเวลา ปิดร้าน |

ตัวแปรแวดล้อม: `PORT` (ค่าเริ่มต้น 3000), `DATA_FILE` (ค่าเริ่มต้น `data/trucks.json`) รูปที่อัปโหลดเก็บในโฟลเดอร์ `uploads/` ข้างไฟล์ข้อมูล

> **หมายเหตุ:** เบราว์เซอร์อนุญาตให้ใช้ GPS เฉพาะบน `https://` หรือ `localhost`
> ตอนใช้งานจริงต้องเปิดผ่าน HTTPS และเจ้าของร้านควรเปิดหน้า `/owner` ค้างไว้
> (แอปขอให้หน้าจอไม่ดับด้วย Wake Lock) เพราะเว็บเบราว์เซอร์จะหยุดส่ง GPS เมื่อปิดจอ

## ทำงานอย่างไร

- `server.js` — เซิร์ฟเวอร์ Node ล้วน: REST API + Server‑Sent Events (`/api/events`) ส่งการเปลี่ยนแปลงแบบสดไปยังทุกแผนที่
  มีตัวจับเวลาตรวจทุก 5 วินาทีเพื่อ “ดับ” ร้านที่หมดเวลา ข้อมูลเก็บเป็นไฟล์ JSON
- เจ้าของร้านได้ **รหัสร้าน** (token) ตอนลงทะเบียน เก็บไว้ในเครื่อง เซิร์ฟเวอร์เก็บเฉพาะค่า hash
  คัดลอกรหัสไปใช้กับเครื่องอื่นได้จากหน้า `/owner`
- `public/map.js` — แผนที่ Leaflet (โหลดไว้ใน `public/vendor/`) โทนกลางคืน หิ่งห้อยแต่ละตัวมีเส้นทางบินสุ่มของตัวเอง
  แต่วนอยู่ในรัศมีราว 28px รอบพิกัดจริง จึงยังชี้ตำแหน่งร้านได้ถูกต้อง

### API

| Method | Path | Body |
| --- | --- | --- |
| GET | `/api/trucks` | — ร้านที่เปิดอยู่ |
| GET | `/api/events` | — SSE: `snapshot`, `update`, `closed` |
| POST | `/api/trucks` | `{ name, menu?, color? }` → `{ id, token }` |
| POST | `/api/trucks/:id/open` | `{ token, lat, lng, durationMin }` (เรียกซ้ำ = ต่อเวลา) |
| POST | `/api/trucks/:id/location` | `{ token, lat, lng }` |
| POST | `/api/trucks/:id/close` | `{ token }` |
| POST | `/api/trucks/:id/me` | `{ token }` |
| POST | `/api/trucks/:id/profile` | `{ token, name?, menu?, color?, photo?, items? }` — `items`: `[{ name, price, category: "food"\|"drink", desc?, photo?, soldOut? }]` สูงสุด 50 รายการ |
| POST | `/api/trucks/:id/upload` | รูป JPEG/PNG/WebP ไม่เกิน 2MB, header `X-Token` → `{ url }` |
