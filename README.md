# ✦ LAMPUS — หิ่งห้อยฟู้ดทรัค

แผนที่ฟู้ดทรัคที่แต่ละร้านเป็น **หิ่งห้อย** บินวนไปมารอบพิกัดจริงของร้าน

- 🟢 **สว่างขึ้น** เมื่อเจ้าของกด “เปิดร้าน” (แอปส่ง GPS ของร้านขึ้นแผนที่)
- 🌗 **ค่อย ๆ หรี่ลง** ในช่วง 15 นาทีสุดท้ายก่อนหมดเวลา
- ⚫ **กะพริบแล้วดับ** เมื่อครบเวลาที่ตั้งไว้ หรือเมื่อเจ้าของกด “ปิดร้าน”
- 🚚 ถ้ารถเคลื่อนที่ หิ่งห้อยจะค่อย ๆ บินตามไปยังตำแหน่งใหม่แบบเรียลไทม์
- 📍 ลูกค้าเห็นว่าตำแหน่งอัปเดตล่าสุดเมื่อไร ถ้าเกิน 5 นาที (เช่น เจ้าของปิดจอ) หิ่งห้อยจะบินช้าลงและแสดงอายุตำแหน่งข้างชื่อร้าน

## ร้านโปรดและข้อความ

- **ร้านโปรด:** ลูกค้าแตะหิ่งห้อยแล้วกด ☆ บันทึกร้าน ร้านจะมี ★ บนแผนที่ และอยู่ในรายการปุ่ม ⭐ (ซ้ายล่าง) พร้อมสถานะเปิด/ปิด
  เก็บในเครื่องลูกค้า (`localStorage`) ไม่ต้องสมัคร
- **แชทลูกค้า ↔ ร้าน:** กด 💬 ส่งข้อความในหน้าร้าน ลูกค้าได้ token ลับต่อแชท (เก็บในเครื่อง) ร้านตอบจากการ์ด
  “ข้อความจากลูกค้า” ในหน้า `/owner` อัปเดตทุกไม่กี่วินาที มีจำนวนข้อความที่ยังไม่อ่านทั้งสองฝั่ง
  ข้อความเก็บใน `chats.json` (200 ข้อความ/แชท, 300 แชท/ร้าน, ลูกค้าส่งได้ 10 ข้อความ/นาที, เปิดแชทใหม่ได้ 10 ครั้ง/ชม./IP)
  API: `POST /api/chats`, `/api/chats/:id`, `/api/chats/:id/send`, `/api/chats/:id/delete`, `/api/chats-summary`, `/api/trucks/:id/chats`

## ค้นหาเจอใน Google (SEO)

- **หน้าร้าน** `/t/:id` (ภาษาอังกฤษ `?lang=en`) เรนเดอร์จากเซิร์ฟเวอร์ (`seo.js`) มีชื่อร้าน เมนู ราคา รูป สถานะเปิด/ปิด
  ข้อมูลแบบ schema.org `FoodEstablishment` และภาพตัวอย่างตอนแชร์ ร้านที่ไม่เคยเปิดจะเป็น `noindex`
- **`/sitemap.xml`** หน้าแรก + ร้านที่เปิดภายใน 90 วัน (ทั้งไทยและอังกฤษ) **`/robots.txt`** กัน `/admin` และ `/api/`
- **ภาพตัวอย่างตอนแชร์ลิงก์** `public/og.png` และ meta tags ในหน้าแผนที่/หน้าเจ้าของร้าน
- ลิงก์ `/?truck=:id` เปิดแผนที่ที่ร้านนั้นทันที เจ้าของร้านแชร์ลิงก์หน้าร้านได้จากหน้า `/owner`
- ตัวแปรแวดล้อม `SITE_URL` (ค่าเริ่มต้น `https://lampus.app`) ใช้สร้างลิงก์เต็มใน sitemap และ meta tags

## ผู้ดูแลระบบ, สำรองข้อมูล และความเป็นส่วนตัว

- **`/admin`** (ใช้ `ADMIN_KEY`): อ่านความคิดเห็น, ดูร้านทั้งหมด, **ระงับ/ยกเลิกการระงับ** ร้าน (หายจากแผนที่ เปิดร้านไม่ได้ หน้าร้าน 404),
  **ลบร้าน** พร้อมรูปและแชท, และ **ดาวน์โหลดไฟล์สำรองข้อมูล** (ร้าน ความคิดเห็น แชท ไม่รวมรูป)
- **สำรองอัตโนมัติ** วันละครั้งที่ `backups/lampus-YYYY-MM-DD.json` ข้างไฟล์ข้อมูล เก็บ 14 วัน
  (อยู่บนดิสก์เดียวกัน: ควรดาวน์โหลดเก็บไว้ที่อื่นเป็นระยะ หรือเปิด Volume Backups ใน Railway)
- **`/privacy`** นโยบายความเป็นส่วนตัว ไทย/อังกฤษ ลิงก์จากแผนที่ หน้าเจ้าของร้าน และหน้าร้าน
- **แจ้งเตือนข้อความใหม่ถึงร้าน**: ตัวเลขบนแท็บ, สั่น และการแจ้งเตือนของระบบ (เมื่ออนุญาต) ระหว่างที่หน้า `/owner` เปิดอยู่
- **Deploy**: `railway.json` เริ่ม `node server.js` และตรวจสุขภาพที่ `/robots.txt`; เซิร์ฟเวอร์ปิดตัวเรียบร้อยเมื่อได้ SIGTERM

## ภาษา / Language

ทุกหน้ามีปุ่มสลับ ไทย / EN (จำไว้ในเครื่อง) ถ้ายังไม่เคยเลือก จะใช้ภาษาไทยเมื่อเบราว์เซอร์ตั้งเป็นไทย นอกนั้นใช้อังกฤษ
ลิงก์ `https://lampus.app/?lang=en` เปิดเป็นภาษาอังกฤษเสมอ ข้อความทั้งหมดอยู่ใน `public/i18n.js`

## ความคิดเห็นถึงผู้สร้าง

ผู้ใช้กด 💬 บนแผนที่ (หรือลิงก์ท้ายหน้าร้าน) เพื่อส่งข้อเสนอแนะ/แจ้งปัญหา ข้อความเก็บใน `feedback.json` ข้างไฟล์ข้อมูล
(จำกัด 5 ข้อความ / 10 นาที ต่อ IP) ผู้สร้างอ่านได้ที่ `/admin` ด้วยรหัสจากตัวแปรแวดล้อม `ADMIN_KEY`
(ไม่ตั้ง = ปิดหน้า admin)

## ติดตั้งเป็นแอป (PWA)

เว็บนี้ติดตั้งลงมือถือได้เหมือนแอป: Android/Chrome กดปุ่ม ⤓ บนแผนที่ (หรือ “ติดตั้งแอป” ในหน้าร้าน),
iPhone เปิดใน Safari › แชร์ › เพิ่มไปยังหน้าจอโฮม ไฟล์ที่เกี่ยวข้อง: `public/manifest.webmanifest`, `public/sw.js`
(service worker: หน้าเว็บโหลดจากเน็ตก่อนเสมอ ใช้ของที่เก็บไว้เมื่อออฟไลน์ ไม่เก็บ `/api/`), `public/pwa.js`, `public/icons/`

## เริ่มใช้งาน

ต้องใช้ Node.js 18 ขึ้นไป ไม่มี dependency ให้ติดตั้ง

```bash
npm start          # http://localhost:3000
npm test
```

| หน้า | สำหรับ |
| --- | --- |
| `/` | ลูกค้า: แผนที่หิ่งห้อย แตะหิ่งห้อยเพื่อดูรูปร้าน เมนูอาหาร/เครื่องดื่มพร้อมรูปและราคา เวลาปิด และนำทาง |
| `/owner` | เจ้าของร้าน: ลงทะเบียน ใส่รูปหน้าร้าน จัดการเมนู (ชื่อ ราคา รูป อาหาร/เครื่องดื่ม ของหมด) เลือกสีแสง เปิดร้าน (เลือกระยะเวลา 15 นาที–1 ชม.) ต่อเวลา ปิดร้าน |

ตัวแปรแวดล้อม: `PORT` (ค่าเริ่มต้น 3000), `DATA_FILE` (ค่าเริ่มต้น `data/trucks.json`) รูปที่อัปโหลดเก็บในโฟลเดอร์ `uploads/` ข้างไฟล์ข้อมูล

> **หมายเหตุ:** เบราว์เซอร์อนุญาตให้ใช้ GPS เฉพาะบน `https://` หรือ `localhost`
> ตอนใช้งานจริงต้องเปิดผ่าน HTTPS และเจ้าของร้านควรเปิดหน้า `/owner` ค้างไว้
> (แอปขอให้หน้าจอไม่ดับด้วย Wake Lock) เพราะเว็บเบราว์เซอร์จะหยุดส่ง GPS เมื่อปิดจอ

## ทำงานอย่างไร

- `server.js` — เซิร์ฟเวอร์ Node ล้วน: REST API + Server‑Sent Events (`/api/events`) ส่งการเปลี่ยนแปลงแบบสดไปยังทุกแผนที่
  มีตัวจับเวลาตรวจทุก 5 วินาทีเพื่อ “ดับ” ร้านที่หมดเวลา ข้อมูลเก็บเป็นไฟล์ JSON
- เจ้าของร้านได้ **รหัสร้าน** (token) ตอนลงทะเบียน เก็บไว้ในเครื่อง เซิร์ฟเวอร์เก็บเฉพาะค่า hash
  คัดลอกรหัสไปใช้กับเครื่องอื่นได้จากหน้า `/owner`
- `public/map.js` — แผนที่ Leaflet (โหลดไว้ใน `public/vendor/`) โทนกลางคืน หิ่งห้อยแต่ละตัวมีเส้นทางบินสุ่มของตัวเอง
  แต่วนอยู่ในรัศมีราว 28px รอบพิกัดจริง จึงยังชี้ตำแหน่งร้านได้ถูกต้อง

### API

| Method | Path | Body |
| --- | --- | --- |
| GET | `/api/trucks` | — ร้านที่เปิดอยู่ |
| GET | `/api/events` | — SSE: `snapshot`, `update`, `closed` |
| POST | `/api/trucks` | `{ name, menu?, color? }` → `{ id, token }` |
| POST | `/api/trucks/:id/open` | `{ token, lat, lng, durationMin }` (เรียกซ้ำ = ต่อเวลา) |
| POST | `/api/trucks/:id/location` | `{ token, lat, lng }` |
| POST | `/api/trucks/:id/close` | `{ token }` |
| POST | `/api/trucks/:id/me` | `{ token }` |
| POST | `/api/trucks/:id/profile` | `{ token, name?, menu?, color?, photo?, items? }` — `items`: `[{ name, price, category: "food"\|"drink", desc?, photo?, soldOut? }]` สูงสุด 50 รายการ |
| POST | `/api/trucks/:id/upload` | รูป JPEG/PNG/WebP ไม่เกิน 2MB, header `X-Token` → `{ url }` |
